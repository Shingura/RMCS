**目标**：用 RMCS 控制龙门架结构，实现发射架的 pitch 与 yaw 控制。

**设备**：C 板；M2006 电机 + C610 电调 × 3；DR16 遥控器。

**机械结构（用户现场确认）**：两个 M2006 竖直放置，同步驱动左右两根杆升降，共同控制 pitch 轴；第三个 M2006 水平放置，通过连杆类结构改变 yaw 轴。

**硬性要求**：
- 用 DR16 的两个通道分别控制 pitch 与 yaw。
- 升降过程中不得出现明显歪斜（左右两侧需保持同步）。
- 单独控制 yaw 时，pitch 角度必须保持不变。

**控制方案（已定稿）**：不做位置闭环（任务只要求上升与下降）。摇杆量经死区后作为目标转速；每个电机保留一个速度环（现成 PID 组件，仅 yaml 配置）；pitch 两侧共用同一目标转速，叠加左右行程之差的比例补偿；同步误差超阈值时停止输出力矩。

**调零方案（已定稿）**：上电时初始状态视为水平，控制器在首个周期记录两侧角度作为各自的相对零点。同步判据是「相对位移相等」，不是「绝对角度相等」。配置文件留两个偏移量参数用于人工修正。

**进度**：已完成。硬件组件、控制器与三个速度环均已实现并通过上机验证。摇杆通道分配为左摇杆上下控 pitch、右摇杆左右控 yaw。注意 DR16 通道定义与遥控器封装的映射假设不一致：控制器需取左摇杆 x 分量与右摇杆 y 分量。yaw 曾出现低频顿挫，去掉速度环积分项并把最大转速提高到 8.0 后缓解。

**上电顺序（用户实测）**：C 板必须先用动力电池供电，再连接电脑 USB。顺序颠倒会触发 C 板保护，表现为 `launch-rmcs` 报「No compatible device found / Serial number read failed」，此时 `lsusb` 仍能看到设备。

**电机 CAN ID（现场确认）**：pitch 左为 3，pitch 右为 2，yaw 为 1。三个 ID 都在 1 到 4 之间，共用标识符 0x200 的 CAN 帧。

**停机与退出规程（用户强调，属合规要求）**：结束运行前必须先把 DR16 两个三挡开关拨到最下方，等电机停稳后才能 Ctrl+C 退出。直接 Ctrl+C 会让电机快速转动一下。代码里已实现双下停机：控制器检测到两个开关同时为 DOWN 时把三个目标转速置零。注意该逻辑需要我们自己实现，遥控器封装不提供。

**用户背景**：熟悉 RMCS，仓库中「DR16 控制 GM6020 速度与角度」由用户本人实现。用户未阅读 RMCS 的封装实现。
